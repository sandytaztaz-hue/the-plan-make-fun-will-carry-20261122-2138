A program that writes one text to `/output/entry.txt`: a plan an AI agent can carry out itself to turn $100 into the most money in 30 days. Day 1 it pulls 200 newly launched Shopify stores from BuiltWith, rewrites one product description free from each store's own public site, and emails it with a $49 offer for all 10 descriptions rewritten in a day, paid by Stripe link — then reinvests the $100 into reaching 500 more stores and raises the price to $99.

## Run it

```sh
node main.ts
```
